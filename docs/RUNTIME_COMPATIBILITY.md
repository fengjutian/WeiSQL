# 浏览器与 Node.js Runtime 兼容性规范

- 状态：接口基线；Node 文件 Reader、缓存层与真实部署测试待实现
- 适用范围：相同 WeiSQL 多文件数据包在浏览器和 Node.js 中的读取语义

## 1. 统一边界

向量读取、ID Map 和 Adapter 只依赖 `ResourceReader`，不得直接调用 `fetch()` 或 Node `fs`。当前接口使用左闭右开 `ByteRange {start,end}`，而不是环境专用的 offset/length API。

共同约束：

- 范围参数是非负安全整数，且 `end >= start`；
- 返回长度必须严格等于请求长度，空范围不触发 I/O；
- 支持 AbortSignal 或等价的明确取消行为；
- `close()` 幂等，关闭后操作返回 `DATABASE_CLOSED`；
- 不安全路径在 I/O 前拒绝；
- 底层错误归一化为稳定 `WeiSQLErrorCode`。

## 2. 能力矩阵

| 能力 | NodeFileResourceReader | HttpResourceReader |
| --- | --- | --- |
| 来源 | 本地包根 | HTTP(S) 包根 |
| 随机读取 | 文件句柄偏移 | HTTP Range |
| 路径边界 | realpath、符号链接、根 containment | origin、base path、重定向 containment |
| 元数据 | stat/fstat | HEAD/响应头 |
| 取消 | 平台能力或 best-effort | AbortSignal |
| 缓存 | 应用级块缓存 | HTTP 缓存 + 应用级块缓存 |
| 当前状态 | 待实现 | 首版已实现并有模拟 Fetch 测试 |

## 3. Node.js 要求

- 使用显式、已解析的真实包根；
- 拒绝绝对路径和包外符号链接/junction；
- 优先打开文件句柄后通过位置参数读取，避免共享文件指针竞态；
- 对短读执行循环补读或明确拒绝，不静默返回；
- `stat` 与实际读取之间的文件变化必须通过句柄级元数据或版本化不可变包降低风险；
- Reader 关闭自身句柄，但共享 Reader 的子组件不得擅自关闭上层资源。

## 4. 浏览器与 CDN 要求

- 只允许 HTTP/HTTPS 基准 URL；
- Range 必须返回 `206 Partial Content`；
- 验证 `Content-Range` 起止、总长度和响应体长度；
- `200 OK` 默认视为不支持 Range；
- CORS 必须允许资源请求并暴露 `Content-Range`、`ETag` 等所需响应头；
- 真实验收必须使用 HTTP 服务或静态托管，`file://` 不能替代；
- 重定向后的 URL 仍需满足 origin 与包根策略。

## 5. ID Map 批量读取

候选行读取流程：

1. 验证行号唯一、非负且在范围内；
2. 排序并合并连续行；
3. 批量读取对应 UInt64 偏移；
4. 合并 JSONL 连续字节区间；
5. 限制单批行数；
6. 将 ID 恢复为候选原始顺序。

后续优化可增加最大合并间隙、最大读取字节数和并发上限，但默认值必须由真实 HTTP/磁盘基准确定，不能预先宣称通用最优值。

## 6. 大数据与内存

100 万条、768 维 Float32 原始数据约为 3.072 GB（十进制）。分块读取降低峰值内存，不降低精确扫描的总 I/O 和计算量。实现必须记录：

- 块大小和并发数；
- 缓存预算与峰值内存；
- 请求次数和下载字节；
- 冷/热缓存 P50/P95；
- 取消后的剩余 I/O；
- 数据集版本切换后的缓存隔离。

## 7. 跨平台测试矩阵

| 测试 | Node.js | 浏览器 | 验收目标 |
| --- | --- | --- | --- |
| Manifest L1/L2 | 必测 | 必测 | 相同输入得到相同结果/错误码 |
| 路径逃逸 | 必测 | 必测 | 无法读取包根外资源 |
| L3 完整性 | 必测 | 必测 | 修改内容或摘要后失败 |
| 本地偏移读取 | 必测 | 不适用 | 无错位、短读或句柄泄漏 |
| HTTP Range | 不适用 | 必测 | 206、范围、总长度和 CORS 正确 |
| 取消 | 必测 | 必测 | 不再启动不需要的新读取 |
| 缓存版本隔离 | 必测 | 必测 | 新旧发布不混用资源块 |
| 大块读取 | 必测 | 必测 | 峰值内存受预算约束 |
| 引擎不可用 | 必测 | 必测 | 明确错误，不伪造结果 |
| 空向量集合 | 必测 | 必测 | 返回 `[]` 且不读取资源 |

浏览器最终验收至少覆盖一个本地可控 HTTP 服务和一个真实静态托管目标（例如 Netlify/CDN）。
