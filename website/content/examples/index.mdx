## 使用方式

每个示例都是**独立片段**：复制后按注释替换路径、集合名或索引名即可。共同前提是仓库已构建：

```bash
npm install
npm run build
```

如果数据包来自 `examples/fixture`，集合名是 `document_embeddings`，维度为 2，度量为 cosine。自己的数据包请以 `manifest.json` 中的声明为准。
