## 三个“没有”

<CardGrid columns={3}>
  <DocCard title="没有服务端进程" index="01">
    部署产物就是一组静态文件，可以用任何静态托管或 CDN 分发。
  </DocCard>
  <DocCard title="没有连接与会话" index="02">
    `open()` 读的是字节，不是远程数据库；没有连接字符串与凭证。
  </DocCard>
  <DocCard title="没有写入路径" index="03">
    Runtime 只读，底层引擎的写能力被显式关掉；更新等于发布新快照。
  </DocCard>
</CardGrid>

## 它解决什么问题

常见的静态站点要加“搜索”，通常只有三种选择：第三方搜索服务、构建期生成索引、或者只做标题匹配。前两者要么引入外部依赖与费用，要么在数据量上来后把索引塞进首屏包。

WeiSQL 的取舍是：把数据变成**可分块读取的静态资产**，让查询发生在客户端，但又不是“把整个数据集下载下来再过滤”。

<CardGrid columns={2}>
  <DocCard title="文档站" index="01">
    同时提供关键词检索、语义检索与 RAG 证据片段，不依赖外部检索服务。
  </DocCard>
  <DocCard title="产品目录 / 知识库" index="02">
    需要离线或内网可用，数据更新有明确发布节奏。
  </DocCard>
  <DocCard title="数据快照分发" index="03">
    Manifest 冻结、摘要可校验、可签名；每次发布是一份不可变快照。
  </DocCard>
  <DocCard title="跨环境一致" index="04">
    同一份数据在 Node.js 脚本与浏览器页面里得到一致的排序结果。
  </DocCard>
</CardGrid>

## 与“把数据库放 CDN 上”的区别

这句话常被用来描述两类完全不同的东西：

- **把数据库文件当静态资源下发**：例如把 SQLite 文件放到 CDN，浏览器下载后交给 WASM 引擎。省掉了服务端，但格式仍是引擎私有页结构。
- **把数据库做成 HTTP 服务**：只是部署在 CDN 边缘，仍然需要凭证、连接和可用性承诺。

WeiSQL 两者都不是。它的核心不是“把引擎搬进浏览器”，而是**把数据布局变成可校验的公开协议**，让引擎成为可替换的实现细节。

| 维度 | CDN 上的数据库文件 | WeiSQL 数据包 |
| --- | --- | --- |
| 格式 | 引擎私有页格式 | 公开协议：Manifest + Parquet + Float32 + JSONL |
| 读取方式 | 通常整文件下载 | 按 `ByteRange` 取需要的块 |
| 结构校验 | 由引擎隐式完成 | L1–L4 分层校验，失败即拒绝 |
| 写入 | 引擎具备写能力，靠部署约束限制 | 无写路径，Runtime 只读 |
| 查询 | 绑定单一引擎 | SQL 引擎可注入；无引擎仍可精确向量、全文与 RAG |
| 权限 | 依赖下载权限 | 包默认公开，敏感数据不得入包 |
| 更新 | 替换文件 | 重建并发布新版本，缓存按版本隔离 |

代价也很具体：需要构建步骤生成数据包，需要接受只读，需要为过滤查询注入 SQL Adapter，也需要自己承担首载体积。

## 一段最小代码

```ts
import { open, HttpResourceReader } from "@weisql/sdk";

const db = await open({
  manifestUrl: "/datasets/demo/manifest.json",
  resourceReader: new HttpResourceReader({ baseUrl: "/datasets/demo/" }),
  verifyChecksums: "all",
});

const hits = await db.vector.search("document_embeddings", queryVector, {
  topK: 5,
  filter: { category: "genetics" },
});

console.log(hits.map(hit => hit.id));
console.log(db.capabilities());
await db.close();
```

这段代码没有后端、没有连接字符串、没有凭证。`filter` 需要注入 SQL Adapter；未注入时返回 `SQL_UNSUPPORTED`，不会静默忽略过滤条件。
